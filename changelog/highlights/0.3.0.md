- **Saves no longer fail on stray characters.** A character XML cannot carry (a bell, a form feed...) is refused or dropped where you set it, never at the save, in Rust, Python and the CLI; in Python, `XmlError` is now also a `ValueError` ([#504](https://github.com/oxoffice-dev/oxoffice/pull/504)).
- **Nothing lost on the round trip.** `&`, `<` and quotes reach every reader (Flat OPC export and ODP read work again with them), attributes are no longer escaped twice, on/off values and line-break `w:clear` survive edits, and a slide title survives ODP ([#503](https://github.com/oxoffice-dev/oxoffice/pull/503), [#488](https://github.com/oxoffice-dev/oxoffice/pull/488), [#482](https://github.com/oxoffice-dev/oxoffice/pull/482), [#496](https://github.com/oxoffice-dev/oxoffice/pull/496), [#505](https://github.com/oxoffice-dev/oxoffice/pull/505)).
- **Fields behave like Word.** `render_template` keeps a tag beside a field, REF reads what Word shows, a quoted operand joins text and nested fields, LibreOffice form fields are read, and bookmark names match in any case ([#481](https://github.com/oxoffice-dev/oxoffice/pull/481), [#489](https://github.com/oxoffice-dev/oxoffice/pull/489), [#497](https://github.com/oxoffice-dev/oxoffice/pull/497), [#480](https://github.com/oxoffice-dev/oxoffice/pull/480), [#502](https://github.com/oxoffice-dev/oxoffice/pull/502)).
- **Copy, cut and import keep documents whole.** Pasted and imported content keeps its ids unique and its bookmarks whole, headers and footers get the body's identities, and removed content leaves no orphan picture, chart or link behind ([#499](https://github.com/oxoffice-dev/oxoffice/pull/499), [#487](https://github.com/oxoffice-dev/oxoffice/pull/487), [#501](https://github.com/oxoffice-dev/oxoffice/pull/501), [#508](https://github.com/oxoffice-dev/oxoffice/pull/508)).
- **Faster slide reordering.** Moving or inserting a slide in Python no longer grows with the deck's shapes: about 50x faster on an 80-slide deck ([#494](https://github.com/oxoffice-dev/oxoffice/pull/494), [#479](https://github.com/oxoffice-dev/oxoffice/pull/479)).
- **Behaviour changes to know.** `add_bookmark` refuses a name that differs from an existing one only by case; a shared notes part is copied when one slide edits it; opening a file with such a character raises `XmlError`.
