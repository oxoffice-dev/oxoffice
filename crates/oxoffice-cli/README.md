# oxoffice-cli

The `oxoffice` command line. One binary carries both document families:

```bash
oxoffice docx --help    # Word documents
oxoffice pptx --help    # PowerPoint presentations
```

`oxoffice docx` is the command tree of `oxoffice-docx-cli` and
`oxoffice pptx` the one of `oxoffice-pptx-cli`. Exit statuses, standard
output and error behaviour are theirs.
