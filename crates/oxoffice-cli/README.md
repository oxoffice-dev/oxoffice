# oxoffice-cli

The `oxoffice` command line. One binary carries the three document families:

```bash
oxoffice docx --help    # Word documents
oxoffice pptx --help    # PowerPoint presentations
oxoffice xlsx --help    # Excel workbooks
```

`oxoffice docx` is the command tree of `oxoffice-docx-cli`,
`oxoffice pptx` the one of `oxoffice-pptx-cli` and `oxoffice xlsx` the one
of `oxoffice-xlsx-cli`. Exit statuses, standard
output and error behaviour are theirs.
